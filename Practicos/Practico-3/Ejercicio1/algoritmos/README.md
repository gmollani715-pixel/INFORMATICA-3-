# Sistema de Gestión de Pedidos – Pizzería

Proyecto práctico en **Java** para simular pedidos de una pizzería y ordenarlos usando distintos algoritmos.

---

## Objetivo
- Manejar una lista de pedidos (agregar, eliminar, actualizar).  
- Ordenar según **tiempo**, **precio** o **nombre del cliente**.  
- Medir y comparar tiempos de ejecución.

---

## Algoritmos usados
- **Inserción** → por tiempo de preparación.  
- **Shellsort** → por precio total.  
- **Quicksort** → por nombre del cliente.
